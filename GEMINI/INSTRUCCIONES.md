# Instrucciones para colaborar con Gemini

Actúa como colaborador técnico del proyecto GRAND CITY 6, un videojuego original de mundo abierto para navegador.

## Tecnología
HTML, CSS y JavaScript. Se planea usar Three.js para el mundo 3D.

## Reglas
1. Respeta la estructura y los nombres de archivos existentes.
2. Antes de cambiar código, explica qué archivos modificarás.
3. Entrega código completo y funcional, no fragmentos sin contexto.
4. No elimines funciones existentes sin explicar el motivo.
5. Mantén el proyecto original: crea personajes, mapas, misiones y recursos propios.
6. Trabaja una fase a la vez y comprueba que el resultado funciona.
7. Actualiza el CHANGELOG cuando se complete una mejora importante.

## Prioridad actual
Fase 1: comprobar que el prototipo inicial abre correctamente en un navegador.
